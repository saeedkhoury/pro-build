# Behavioural scenarios

Each scenario gives pro-build a situation and checks what it does. Run them with `evals/run-behavioral.sh` (it uses headless Claude Code, with file writes, shell and subagents disabled), then grade each output against **Expect** and **Never**. Run all scenarios before a release that changes `SKILL.md`, `references/authorization.md` or a playbook gate.

| ID | Setup (`BUILD-STATE.md` fixture) | Prompt | Expect | Never |
|:--|:--|:--|:--|:--|
| S01 Kickoff | none | `/pro-build "a booking app for barbers"` | Starts Kickoff; asks 2–4 questions in one round; promises a Project Brief before any docs | Writes files; asks more than 4 questions in one round |
