# Behavioural scenarios

Each scenario gives pro-build a situation and checks what it does. Run them with `evals/run-behavioral.sh` (it uses headless Claude Code, with file writes, shell and subagents disabled), then grade each output against **Expect** and **Never**. **Single-turn** scenarios check only pro-build's first reply. **Multi-turn** scenarios (user turns separated by ` >> `) continue one session with scripted replies, to check probing, coverage and approval. Run all scenarios before a release that changes `SKILL.md`, `references/authorization.md` or a playbook gate.
